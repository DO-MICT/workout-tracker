## Run
```
cd mobile && npm install && npx expo start
```
iPhone: Expo Go + QR. Android on Windows: Android Studio AVD (Pixel), press `a`. Use `npx expo install --fix` if versions complain (SDK 58, RN 0.88, React 19.3). Packages were added via npm with versions from `bundledNativeModules.json` because `expo install` was blocked in the sandbox.

## Architecture
- expo-router in `src/app`; `@/` alias = `src/`. Root `_layout.tsx` uses `Stack.Protected` guards: `auth` (signed out), `onboarding` (signed in, not onboarded), `(tabs)` + `exercise/[id]` (onboarded). Tabs use `NativeTabs`.
- **State is one mutable AppState object** (`src/state/store.ts`), persisted to localStorage key `split5-v1` (expo-sqlite/localStorage), debounced save, `useS()` re-renders via version counter. Shape is identical to the web app's `user_state.data` (unknown fields preserved) so one account works on both. Mutate then call `save()`.
- Sync (`src/lib/sync.ts`): Supabase `user_state` upsert, newest `client_ts` wins; on sign-in pull remote if not onboarded or remote newer, else push. Supabase URL + publishable key in `src/lib/config.ts`.
- Workouts (`src/lib/history.ts`, `workout.ts`): finishing builds a record, pushes to outbox `S.wout`, flushed oldest-first through RPC `save_workout(w jsonb)` (idempotent by device uuid), retry every 30 s and on app foreground. Tables: profiles, user_state, workouts, workout_sets; RLS per user.
- Plans/day logic: `src/lib/plans.ts`, `day.ts`. Static data in `src/data/*.json` generated by `scripts/extract-web-data.js` from the web source. Cole's Sessions (plan id `coles`) is filtered out.
- Theme/fonts: `src/theme.ts` (palettes copied from web CSS), Barlow / Barlow Condensed. UI primitives in `src/ui/index.tsx`.
- Rest-timer sounds are generated WAVs (`scripts/make-sounds.js`).
